GitHub Pagesは、GitHub上に保存したファイルを使って、Webサイトやブログを公開できるサービスです。

通常、Webサイトを公開するには、レンタルサーバーを契約し、サーバーの設定を行う必要があります。一方、GitHub Pagesでは、GitHubのリポジトリに記事やページのファイルを保存することで、Webサイトとして公開できます。

個人サイト、研究者のプロフィールページ、研究プロジェクトの紹介、技術ブログ、教育資料など、さまざまな用途に利用できます。

## どのような仕組みか

GitHub Pagesでは、主に次の流れでWebサイトが公開されます。

```text
記事やページを作る
        ↓
GitHubに保存する
        ↓
Webサイトとして公開される
```

記事はMarkdownという形式で書くことができます。

Markdownでは、簡単な記号を使って見出し、箇条書き、リンク、画像などを記述します。

例えば、次のように書きます。

```markdown
## GitHub Pagesの特徴

- Webサイトを無料で公開できる
- Markdownで記事を書ける
- 変更履歴をGitHub上に残せる
```

このファイルをGitHubに保存すると、ブラウザで読みやすいWebページとして表示されます。

## Jekyllとの関係

GitHub Pagesでは、Jekyllという仕組みがよく使われます。

Jekyllは、Markdownで書かれた記事をWebページへ変換するツールです。

Jekyllを利用すると、次のようなブログ機能を作れます。

* 記事一覧
* カテゴリー
* タグ
* 共通メニュー
* Aboutページ
* 共通フッター

このサイトでは、JekyllのテーマであるChirpyを使用しています。

## GitHub Pagesの特徴

GitHub Pagesの主な特徴は、次の3点です。

### 基本的に無料で使える

独自ドメインを使わなければ、通常は次のようなURLでサイトを公開できます。

```text
https://ユーザー名.github.io
```

### ファイルとして管理できる

記事やページはGitHub上のファイルとして保存されます。

そのため、変更履歴を確認したり、以前の状態に戻したりできます。

### 研究コードと連携しやすい

研究方法を解説する記事から、RやPythonのコードを保存したGitHubリポジトリへ直接リンクできます。

研究記事、解析コード、サンプルデータを一つのGitHubアカウント内で整理できる点は、研究者にとって大きな利点です。

## まとめ

GitHub Pagesは、GitHub上のファイルを使ってWebサイトを公開できるサービスです。

Markdownで記事を書き、GitHubに保存することで、個人サイトやブログとして公開できます。

特に、研究コードや研究資料とWebサイトを一緒に管理したい研究者に適した仕組みです。
