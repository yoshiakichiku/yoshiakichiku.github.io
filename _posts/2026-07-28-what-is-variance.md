# 分散とは？データのばらつきを表す基本指標をわかりやすく解説

**結論：分散とは、データが平均値からどれくらい散らばっているか（ばらつき）を数値化した指標です。**

**分散が大きいほどデータは広く散らばり、分散が小さいほどデータは平均付近に集まっています。**

**標準偏差や分散分析（ANOVA）など、多くの統計手法の基礎となる概念であり、統計学を学ぶ上で必ず理解しておきたい指標です。**

---

# 分散とは？

分散（Variance）は、**データのばらつきの大きさ**を表す統計量です。

平均値だけでは、データがどの程度散らばっているのかは分かりません。

例えば、次の2つのデータを見てみましょう。

```
A：49, 50, 50, 51, 50
平均 = 50
```

```
B：20, 35, 50, 65, 80
平均 = 50
```

どちらも平均は50ですが、

Aは平均付近に集まっている一方で、Bは広く散らばっています。

この「散らばり具合」を数値化したものが分散です。

---

# なぜ平均だけでは不十分なのか？

研究では平均値だけでは十分な情報を得られません。

例えば、

|群|平均網膜厚|
|---|---:|
|A群|300 μm|
|B群|300 μm|

平均は同じでも、

- A群はほぼ全員300 μm
- B群は200〜400 μmまでばらばら

という可能性があります。

この違いを表現できるのが分散です。

---

# 分散の考え方

分散は、

**「各データが平均からどれくらい離れているか」**

を基に計算されます。

平均からの差を「偏差」と呼びます。

しかし、そのまま足し合わせると、

プラスとマイナスが打ち消し合ってしまいます。

そのため、

1. 平均との差（偏差）を求める
2. 偏差を二乗する
3. 全体の平均を求める

という手順で計算します。

---

# 分散の計算式

母分散は次の式で表されます。

$$
\sigma^2=
\frac{1}{N}
\sum_{i=1}^{N}(x_i-\mu)^2
$$

ここで、

- $x_i$：各データ
- $\mu$：平均値
- $N$：データ数

を表します。

標本分散では、分母は **Nではなく N−1** になります。

これは母集団の分散を偏りなく推定するためです。

---

# なぜ二乗するの？

平均との差をそのまま使うと、

```
-3
+3
```

を足すと0になってしまいます。

そこで二乗すると、

```
(-3)^2 = 9

(+3)^2 = 9
```

となり、

平均から離れているほど大きな値になります。

これによって、ばらつきを正しく評価できます。

---

# 分散の単位に注意

分散には一つ欠点があります。

例えば身長（cm）の分散なら、

```
cm²
```

という単位になります。

そのため、

実際には分散よりも

**標準偏差（Standard Deviation）**

の方がよく利用されます。

標準偏差は、

分散の平方根です。

$$
SD=\sqrt{Variance}
$$

単位が元のデータと同じになるため、解釈しやすくなります。

---

# 分散が大きい・小さいとは？

例えば、

## 分散が小さい

```
98
99
100
101
102
```

平均付近に集まっています。

---

## 分散が大きい

```
60
80
100
120
140
```

平均は同じでも、大きく散らばっています。

研究では、

分散が大きいほど個人差が大きいことを意味します。

---

# 分散と標準偏差の違い

この2つは混同されやすい指標です。

|項目|分散|標準偏差|
|---|---|---|
|意味|ばらつき|ばらつき|
|単位|元の単位の二乗|元の単位|
|利用頻度|理論計算で多い|論文で多い|

医学論文では、

平均±標準偏差

で結果を示すことが一般的です。

---

# 分散分析（ANOVA）の「分散」とは？

分散分析という名前にも「分散」が使われています。

これは、

**群間のばらつき**

と

**群内のばらつき**

を比較する解析だからです。

群間のばらつきが群内のばらつきより十分大きければ、

平均値に差があると判断します。

---

# Rで分散を計算する方法

分散は次のように計算できます。

```R
var(data$variable)
```

標準偏差は

```R
sd(data$variable)
```

で求められます。

---

# 医学研究での活用例

分散はさまざまな解析で利用されています。

例えば、

- t検定
- 分散分析（ANOVA）
- 回帰分析
- 線形混合効果モデル
- ICC（級内相関係数）
- Bland–Altman解析

など、多くの統計手法で重要な役割を果たします。

ばらつきを理解することは、測定精度や個人差を評価する上でも欠かせません。

---

# よくある誤解

## 分散が小さいほど良い？

必ずしもそうではありません。

例えば、

患者集団の重症度が異なれば、分散が大きくなるのは自然です。

一方、測定機器の再現性評価では、

分散が小さいほど測定誤差が少なく、良い測定法であると考えられます。

つまり、

**何のばらつきを評価しているのか**

を考えることが重要です。

---

# まとめ

分散は、データのばらつきを数値化する最も基本的な統計指標です。

ポイントをまとめると、

- 分散は平均からの散らばりを表す
- 分散が大きいほどデータは広く散らばる
- 偏差を二乗して計算する
- 標準偏差は分散の平方根である
- 分散分析や回帰分析など多くの統計手法の基礎となる
- 医学論文では標準偏差が用いられることが多い

分散の考え方を理解すると、標準偏差や分散分析、回帰分析などの統計手法も理解しやすくなります。統計学を学ぶ際には、まず押さえておきたい基本概念の一つです。
