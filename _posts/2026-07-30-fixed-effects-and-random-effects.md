# 固定効果とランダム効果とは？

線形混合効果モデルを学ぶと、必ず出てくるのが「固定効果」と「ランダム効果」です。

この2つの違いは、初めて学ぶと分かりにくく感じます。

しかし、考え方そのものはそれほど複雑ではありません。

簡単にいうと、

* **固定効果**：研究者が知りたい平均的な効果
* **ランダム効果**：患者や施設などによる個別の違い

です。

この記事では、医学研究の具体例を使いながら、固定効果とランダム効果の違いを分かりやすく解説します。

## まず、線形混合効果モデルとは？

線形混合効果モデルは、固定効果とランダム効果を同時に扱う統計モデルです。

通常の線形回帰分析では、すべての観測値が互いに独立していることを前提とします。

しかし、医学研究では次のようなデータを扱うことがあります。

* 同じ患者を複数回測定する
* 同じ患者の左右眼を解析する
* 複数の施設から患者を集める
* 同じ医師が複数の患者を診察する

このようなデータでは、同じ患者や同じ施設から得られた観測値は互いに似ています。

線形混合効果モデルでは、このようなデータのまとまりをランダム効果として扱います。

## 固定効果とは？

固定効果とは、研究者が推定したい平均的な効果です。

例えば、治療前後の網膜厚を比較する研究を考えます。

研究者が知りたいことは、

> 治療によって、平均的に網膜厚がどの程度変化したか

です。

この場合、治療の有無や測定時期が固定効果になります。

医学研究で固定効果として扱われることが多い変数には、次のようなものがあります。

* 治療群
* 時間
* 年齢
* 性別
* 疾患の有無
* 眼軸長
* 血圧
* 治療と時間の交互作用

固定効果は、研究対象全体に共通する傾向を表します。

## 固定効果の具体例

例えば、年齢と網膜厚の関係を調べるとします。

```r
retinal_thickness ~ age
```

このモデルでは、年齢が固定効果です。

推定される回帰係数が `-0.5` であれば、

> 年齢が1歳高くなるごとに、網膜厚が平均0.5 μm薄くなる

と解釈できます。

この「平均的にどの程度変化するか」が固定効果です。

## ランダム効果とは？

ランダム効果とは、患者、眼、施設などによる個別の違いを表す効果です。

例えば、同じ年齢であっても、すべての患者の網膜厚が同じではありません。

* もともと網膜が厚い患者
* もともと網膜が薄い患者

がいます。

この個人差を無視すると、同じ患者から得られた複数の測定値を、すべて独立したデータとして扱うことになります。

ランダム効果を入れることで、患者ごとの違いをモデルに反映できます。

## ランダム切片とは？

最も基本的なランダム効果は、ランダム切片です。

例えば、次のモデルです。

```r
retinal_thickness ~ age + (1 | subject_id)
```

`(1 | subject_id)` は、患者ごとに異なる切片を持たせることを意味します。

つまり、

> 年齢による平均的な変化は共通だが、もともとの網膜厚は患者ごとに異なる

というモデルです。

患者Aは全体平均より厚い、患者Bは全体平均より薄い、という違いを表現できます。

## ランダム傾きとは？

患者によって、変化の速さも異なることがあります。

例えば、経時的に網膜厚を測定した場合、

* 急速に薄くなる患者
* ゆっくり薄くなる患者
* ほとんど変化しない患者

がいるかもしれません。

この違いを表現するのがランダム傾きです。

```r
retinal_thickness ~ time + (time | subject_id)
```

このモデルでは、患者ごとに切片だけでなく、時間に対する傾きも異なることを許容します。

ただし、ランダム傾きを含むモデルは複雑になるため、症例数や測定回数が少ない場合には推定が不安定になることがあります。

## 固定効果とランダム効果の違い

固定効果とランダム効果の違いを整理すると、次のようになります。

| 項目     | 固定効果              | ランダム効果           |              |
| ------ | ----------------- | ---------------- | ------------ |
| 主な役割   | 平均的な効果を推定する       | 個体や集団ごとの違いを表す    |              |
| 例      | 年齢、治療、時間、性別       | 患者、眼、施設、医師       |              |
| 研究上の関心 | 直接知りたいことが多い       | データの相関やばらつきを調整する |              |
| 主な出力   | 回帰係数、信頼区間、P値      | 分散、標準偏差          |              |
| Rでの書き方 | `age + treatment` | `(1              | subject_id)` |

## 同じ変数でも固定効果にもランダム効果にもなり得る

変数の名前だけで、固定効果かランダム効果かが決まるわけではありません。

研究目的によって扱い方が変わります。

例えば、3つの特定施設を比較し、それぞれの施設差を知りたい場合、施設を固定効果として扱うことがあります。

```r
outcome ~ hospital
```

一方、多数の施設から患者を集め、施設ごとの差そのものには関心がなく、施設内のデータが似ることだけを考慮したい場合は、施設をランダム効果として扱えます。

```r
outcome ~ treatment + (1 | hospital)
```

重要なのは、

> その変数の各カテゴリーを個別に比較したいのか、それとも母集団から抽出された集団として扱いたいのか

を考えることです。

## 左右眼のデータではどう考えるか？

眼科研究では、同じ患者の左右眼を解析することがあります。

左右眼は同じ患者に属するため、完全に独立ではありません。

例えば、各眼を複数回測定する研究では、次のような階層があります。

* 患者
* 患者内の眼
* 各眼の反復測定

この場合、次のようなモデルを使用できます。

```r
measurement ~ 1 +
  (1 | subject_id) +
  (1 | subject_id:eye)
```

このモデルでは、

* `(1 | subject_id)`：患者間のばらつき
* `(1 | subject_id:eye)`：同じ患者内の左右眼のばらつき
* 残差：同じ眼を繰り返し測定したときのばらつき

を分けて推定します。

左右眼を扱う研究では、患者と眼の階層構造を意識することが重要です。

## 固定効果に入れるべき変数

固定効果には、一般に次のような変数を入れます。

* 主要な説明変数
* 交絡因子
* 調整したい背景因子
* 時間や治療群
* 研究仮説に関係する交互作用

ただし、変数を多く入れればよいわけではありません。

症例数に対して固定効果が多すぎると、推定が不安定になります。

解析前に、

> この変数をモデルに入れる理由は何か

を明確にする必要があります。

## ランダム効果に入れるべき変数

ランダム効果として検討されるのは、観測値がまとまる単位です。

例えば、

* 患者
* 眼
* 施設
* 医師
* 家族
* 学校
* 実験ロット

などです。

ただし、カテゴリー数が非常に少ない変数をランダム効果として扱う場合は注意が必要です。

例えば、施設が2つしかない場合、施設間分散を安定して推定するのは難しいことがあります。

## よくある誤解

### ランダム効果は、無作為に選んだ変数という意味ではない

「ランダム」という言葉から、無作為化された変数を連想するかもしれません。

しかし、ランダム効果は無作為化の有無を表す言葉ではありません。

患者や施設ごとの効果を、ある分布から生じたばらつきとして扱うという意味です。

### 固定効果の方が重要で、ランダム効果は補助的とは限らない

研究上の結論は固定効果を中心に述べることが多いですが、ランダム効果を正しく設定しないと、標準誤差やP値が不適切になる可能性があります。

ランダム効果は、データ構造を正しく表現するために重要です。

### 患者IDを固定効果として入れれば同じとは限らない

患者IDを固定効果として入れる方法もありますが、患者数が多いと大量の係数を推定することになります。

ランダム効果を使えば、患者間の違いを分散としてまとめて扱えます。

研究目的やデータ構造に応じて選択する必要があります。

## まとめ

固定効果とランダム効果は、次のように考えると分かりやすくなります。

* 固定効果は、研究者が知りたい平均的な効果
* ランダム効果は、患者や施設などによる個別の違い
* ランダム切片は、個体ごとの出発点の違い
* ランダム傾きは、個体ごとの変化量の違い
* 同じ患者から複数のデータを得る場合、ランダム効果が重要になる

線形混合効果モデルを組み立てるときは、最初に次の2つを考えると整理しやすくなります。

> 研究で知りたい平均的な効果は何か？

> どの観測値が、同じ患者や施設に属しているか？

前者が固定効果、後者がランダム効果を考える出発点になります。
