回帰モデル（Regression Model）は、**ある変数（目的変数）が、別の変数（説明変数）の影響をどのように受けるかを数式で表現する統計モデル**です。

医学論文では最も頻繁に利用される解析手法の一つであり、年齢や性別、治療方法などが結果にどの程度影響するのかを定量的に評価できます。

この記事では、

- 回帰モデルとは何か
- なぜ使うのか
- 相関との違い
- 代表的な回帰モデル
- 医学研究での利用例

を初心者向けに解説します。

---

# 回帰モデルとは？

回帰モデルとは、

**「説明変数から目的変数を予測・説明するための数理モデル」**

です。

例えば、

- 年齢が高いほど血圧は上がるのか？
- BMIが高いほどHbA1cは高いのか？
- OCTで網膜が厚いほど視力は悪いのか？

このような疑問を数式で表現します。

最も単純な回帰モデルは

$$
Y=\beta_0+\beta_1X+\varepsilon
$$

です。

ここで

- \(Y\)：目的変数
- \(X\)：説明変数
- \(\beta_0\)：切片
- \(\beta_1\)：回帰係数
- \(\varepsilon\)：誤差

を表します。

---

# 回帰モデルで何が分かる？

回帰モデルでは

- 説明変数が結果に影響しているか
- どの程度影響するか
- 他の要因を調整しても影響が残るか

を調べることができます。

例えば

「年齢が1歳高くなると網膜厚は0.4 μm薄くなる」

という結果は回帰モデルから得られます。

---

# 相関との違い

初心者が最も混乱するのが相関との違いです。

| 相関 | 回帰モデル |
|------|-----------|
| 関係の強さを見る | 影響量を推定する |
| 対称的 | 説明変数と目的変数を区別する |
| rを求める | 回帰係数を求める |
| 予測には向かない | 予測にも利用できる |

例えば、

身長と体重には相関があります。

しかし

「身長から体重を予測する」

のであれば回帰モデルを使います。

---

# 回帰係数とは？

回帰モデルで最も重要なのが回帰係数です。

例えば

$$
Y=120+2X
$$

なら

年齢が1増えると

平均してYは2増える

ことを意味します。

つまり、

回帰係数は

**説明変数が1単位変化したときの目的変数の変化量**

です。

---

# 単回帰分析

説明変数が1つだけなら

**単回帰分析**

と呼ばれます。

例えば

- 年齢
- BMI
- 眼軸長

だけで結果を説明する場合です。

---

# 重回帰分析

説明変数が複数になると

**重回帰分析**

になります。

例えば

$$
網膜厚=
年齢+
性別+
眼軸長+
糖尿病期間
$$

のようなモデルです。

医学論文ではこちらの方が一般的です。

---

# 回帰モデルが必要な理由

例えば

年齢が高い患者ほど糖尿病期間も長いとします。

この場合、

年齢だけを見ると

実際には糖尿病期間の影響を見ている可能性があります。

そこで

年齢

糖尿病期間

性別

などを同時にモデルへ入れることで

それぞれ独立した影響を推定できます。

これを

**交絡因子を調整する**

と呼びます。

---

# 代表的な回帰モデル

医学研究では目的変数によって使用するモデルが変わります。

| 目的変数 | 回帰モデル |
|-----------|----------------|
| 連続値 | 線形回帰 |
| 二値 | ロジスティック回帰 |
| 生存時間 | Cox回帰 |
| カウント | ポアソン回帰 |
| 繰り返し測定 | 線形混合効果モデル |
| 非線形 | GAMなど |

解析手法はデータの種類に合わせて選択します。

---

# 線形回帰モデル

最も基本となるモデルです。

目的変数が

- 血圧
- 身長
- 網膜厚
- 視力

など連続値の場合に利用します。

例えば

「年齢が高いほどRNFLは薄くなるか」

を評価できます。

---

# ロジスティック回帰

結果が

- 発症した
- 発症しなかった

のような二値の場合に利用します。

例えば

- 再発したか
- 視力改善したか
- 合併症が起こったか

などです。

結果は

**オッズ比（Odds Ratio）**

として報告されることが多くあります。

---

# Cox回帰

生存時間解析に利用します。

例えば

- 再発までの日数
- 死亡までの期間
- 再手術までの時間

などです。

結果は

**ハザード比（Hazard Ratio）**

として報告されます。

---

# 線形混合効果モデル

眼科研究では非常によく利用されます。

例えば

- 左右眼を含む
- 繰り返し測定がある
- 長期経過を解析する

場合です。

通常の回帰分析では

「データ同士が独立している」

ことを仮定しています。

しかし

左右眼や経時測定では

同じ患者のデータ同士は似ています。

その相関を考慮できるのが

線形混合効果モデルです。

近年の眼科論文では非常に多く採用されています。

---

# 回帰モデルで確認すること

モデルを作ったら

以下を確認します。

- 回帰係数
- 95%信頼区間
- p値
- 残差
- 外れ値
- モデルの当てはまり

特に

「p値だけ」

を見るのではなく、

回帰係数の大きさも重要です。

---

# Rでの例

単回帰分析

```r
model <- lm(y ~ age, data = data)
summary(model)
```

重回帰分析

```r
model <- lm(
  thickness ~ age + sex + axial_length,
  data = data
)

summary(model)
```

線形混合効果モデル

```r
library(lme4)

model <- lmer(
  thickness ~ age + sex + (1 | subject),
  data = data
)

summary(model)
```

# 医学研究での具体例

例えば

「糖尿病黄斑浮腫患者30眼」

について解析するとします。

目的変数

- 中心網膜厚

説明変数

- 年齢
- 性別
- HbA1c
- 糖尿病期間
- 眼軸長

重回帰分析を行うことで

「他の要因を調整してもHbA1cは網膜厚と関連しているか」

を評価できます。

---

# よくある質問

## 相関係数だけではだめ？

相関は関係を示すだけであり、

他の要因を調整できません。

医学研究では回帰分析が推奨されます。

---

## 説明変数はいくつでも入れてよい？

多すぎると過学習になります。

一般には症例数とのバランスを考えて選択します。

---

## p値だけ見ればよい？

いいえ。

回帰係数

95%信頼区間

効果量

も合わせて解釈することが重要です。

---

# まとめ

回帰モデルは、説明変数と目的変数の関係を数式で表現し、影響の大きさを定量的に評価する統計手法です。

単回帰分析、重回帰分析、ロジスティック回帰、Cox回帰、線形混合効果モデルなど、目的変数や研究デザインに応じて適切なモデルを選択する必要があります。

医学研究では、単に関連を見るだけでなく、交絡因子を調整したうえで独立した影響を評価することが重要です。回帰モデルを理解することは、論文を正しく読み、質の高い研究を行うための基礎となります。
