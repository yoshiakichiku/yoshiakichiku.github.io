QQプロット（Q-Q Plot）は、データが正規分布に従っているかを視覚的に確認するための代表的なグラフです。

Shapiro-Wilk検定と併用することで、P値だけでは分からない分布の特徴を把握できます。

回帰分析では目的変数ではなく「残差」のQQプロットを確認することが重要です。

---

# QQプロットとは？

QQプロット（Quantile-Quantile Plot）は、**観測データの分位点（Quantile）**と**理論上の正規分布の分位点**を比較するグラフです。

データが正規分布に従っていれば、点はほぼ一直線上に並びます。

そのため、QQプロットは正規性を視覚的に評価する最も代表的な方法の一つです。

---

# なぜQQプロットを使うのか？

多くの統計手法では、データまたは残差が正規分布に従うことを仮定しています。

例えば、

- t検定
- 分散分析（ANOVA）
- 線形回帰
- 線形混合効果モデル

などでは正規性が重要な前提となります。

QQプロットを見ることで、

- 正規分布に近いか
- 外れ値があるか
- 分布が歪んでいるか

を直感的に確認できます。

---

# QQプロットの仕組み

QQプロットでは、

- 横軸：理論上の正規分布の分位点
- 縦軸：実際のデータの分位点

を対応させて描画します。

もしデータが正規分布に従っていれば、

```
        ●

      ●

    ●

  ●

●
```

のように点が一直線に並びます。

---

# 正規分布の場合

理想的なQQプロットは、

```
          ●

        ●

      ●

    ●

  ●

●
```

のようになります。

多少のばらつきは問題ありませんが、

全体として直線状であれば、

正規分布に近いと考えられます。

---

# 右に歪んだ分布

データが右に歪んでいる場合は、

```
            ●

         ●

      ●

    ●

 ●

●
```

のように、

両端で直線から外れた形になります。

これは右裾が長い分布（右偏分布）でよく見られます。

---

# 左に歪んだ分布

逆に左へ歪んだ分布では、

```
●

  ●

    ●

      ●

         ●

            ●
```

のような形になります。

---

# 外れ値がある場合

外れ値が存在すると、

一部の点だけが大きく直線から外れます。

例えば、

```
       ●

     ●

   ●

 ●

●




                ●
```

のように、

最後の点だけが大きく離れることがあります。

この場合は、

外れ値の影響を受けている可能性があります。

---

# QQプロットとShapiro-Wilk検定の違い

QQプロットとShapiro-Wilk検定は、どちらも正規性を評価する方法ですが、それぞれ役割が異なります。

| QQプロット | Shapiro-Wilk検定 |
|------------|------------------|
| 視覚的評価 | 統計学的検定 |
| 分布の形が分かる | P値が得られる |
| 外れ値を発見しやすい | 客観的に判定できる |

実際の研究では、両者を組み合わせて評価することが推奨されています。

---

# P値だけでは不十分な理由

例えば、

症例数が500例ある場合、

ごくわずかな歪みでも

```
P < 0.001
```

となることがあります。

しかし、

QQプロットを見ると、

ほぼ一直線であることも珍しくありません。

逆に、

症例数が少ない場合は、

Shapiro-Wilk検定で有意差が出なくても、

QQプロットでは明らかな歪みが見つかることがあります。

そのため、

P値だけで判断するのではなく、

必ずQQプロットも確認することが重要です。

---

# 回帰分析では残差を見る

回帰分析では、

目的変数そのものではなく、

**残差が正規分布に従うこと**

が仮定されています。

そのため、

線形回帰では、

残差のQQプロットを確認します。

残差が一直線に並んでいれば、

正規性の仮定は概ね満たされていると考えられます。

---

# RでQQプロットを描く方法

データそのものを確認する場合は、

```r
qqnorm(x)
qqline(x)
```

で作成できます。

線形回帰では、

```r
model <- lm(y ~ x, data = df)

qqnorm(residuals(model))
qqline(residuals(model))
```

を実行します。

---

# よくある質問

## 完全に一直線でなければダメ？

いいえ。

実際のデータでは多少のばらつきは普通です。

全体として直線状であれば問題ないことが多くあります。

---

## QQプロットだけで判断してよい？

いいえ。

QQプロットは視覚的評価です。

Shapiro-Wilk検定やヒストグラムなども併せて確認することが推奨されます。

---

## どの程度曲がると問題？

明確な基準はありません。

両端だけわずかに外れる程度であれば問題ないことも多くありますが、

大きくS字状に曲がる場合や、

多くの点が直線から離れている場合には、

正規性を満たしていない可能性があります。

---

# QQプロットを見るときのポイント

QQプロットでは、

- 点が一直線上に並んでいるか
- 両端だけ外れていないか
- S字状になっていないか
- 外れ値が存在しないか

を確認することが重要です。

統計解析では、P値だけで正規性を判断するのではなく、QQプロットによる視覚的評価を組み合わせることで、データの特徴をより正確に把握できます。

---

# まとめ

QQプロットは、データや残差が正規分布に従っているかを視覚的に評価するための代表的な方法です。

Shapiro-Wilk検定だけでは分からない分布の歪みや外れ値を確認できるため、多くの統計解析で利用されています。

特に回帰分析では、目的変数ではなく残差のQQプロットを確認することが重要であり、統計解析の信頼性を高めるために欠かせない手法です。
