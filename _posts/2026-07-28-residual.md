残差とは、「実際に観測された値」と「統計モデルが予測した値」の差のことです。

回帰分析では、残差を見ることでモデルがどの程度データを説明できているかを評価できます。

統計解析では、係数やP値だけでなく、残差を確認することが信頼できる解析を行うための重要なポイントになります。

---

## 残差とは？

残差（Residual）は、**観測値と予測値の差**です。

式で表すと

$$
e_i = y_i - \hat{y}_i
$$

となります。

例えば、ある回帰モデルが「身長170 cmなら体重65 kg」と予測したとします。

実際の体重が68 kgだった場合、

```
残差 = 68 - 65 = 3 kg
```

となります。

逆に実際の体重が63 kgなら

```
残差 = 63 - 65 = -2 kg
```

になります。

つまり、

- 正の残差：予測より実際の値が大きい
- 負の残差：予測より実際の値が小さい

という意味になります。

---

## 残差と誤差の違い

残差と誤差は混同されやすいですが、意味は異なります。

### 誤差（Error）

誤差とは、

```
真の値 − モデル
```

の差です。

しかし、真の値は通常分かりません。

---

### 残差（Residual）

一方、残差は

```
観測値 − モデルの予測値
```

であり、実際のデータから計算できます。

そのため、統計解析では誤差の代わりに残差を用いてモデルを評価します。

---

## 回帰分析で残差が重要な理由

回帰分析では、

$$
y = \beta_0 + \beta_1 x
$$

のようなモデルを作ります。

しかし、実際のデータは一直線上には並びません。

```
        ●

    ●

          ●

      ／
     ／
    ／

 ●
```

データ点と回帰直線とのズレが残差です。

この残差が小さいほど、

「モデルがデータをよく説明できている」

ことになります。

---

## 残差が大きい場合

残差が大きい場合には、

- モデルが適切ではない
- 外れ値がある
- 説明変数が不足している
- 非線形な関係がある

などが考えられます。

そのため、残差はモデル改善の重要なヒントになります。

---

## 残差プロットとは？

回帰分析では、残差を図にした「残差プロット（Residual Plot）」を確認します。

理想的には、

```
    |
  ● |     ●
----+--------------
 ●  |   ●
    |      ●
```

のように0を中心としてランダムに散らばります。

一方、

```
●

   ●

      ●

          ●
```

のような規則性がある場合、

- 線形モデルでは不十分
- 分散が一定でない（不均一分散）
- モデルに問題がある

可能性があります。

---

## 残差から分かること

残差を見ることで、

- モデルの当てはまり
- 外れ値
- 分散の一定性
- 正規性
- 非線形性

など、多くの情報が得られます。

そのため、統計解析では回帰係数だけではなく、必ず残差も確認することが推奨されています。

---

## 残差の正規性とは？

線形回帰では、

**残差がおおむね正規分布に従う**

ことが仮定されています。

完全に正規分布である必要はありませんが、

- QQプロット
- ヒストグラム
- Shapiro-Wilk検定

などを用いて確認することがあります。

---

## 残差の分散が一定であること（等分散性）

回帰分析では、

残差のばらつきが説明変数に関係なく一定であること（等分散性）も重要です。

もし、

```
小さいxでは小さい残差

大きいxでは大きな残差
```

となる場合は、不均一分散（Heteroscedasticity）が疑われます。

この場合、

- ロバスト標準誤差
- 重み付き回帰
- 変数変換

などを検討します。

---

## 残差平方和（RSS）とは？

回帰分析では、

残差を単純に足すと

```
正の残差
負の残差
```

が打ち消し合ってしまいます。

そこで、

残差を二乗して合計した

```
Residual Sum of Squares（RSS）
```

を利用します。

$$
RSS
=
\sum_{i=1}^{n}
\left(y_i-\hat{y}_i\right)^2
$$

RSSが小さいほど、

モデルの予測精度は高いと考えられます。

最小二乗法（Least Squares Method）は、このRSSが最小となるように回帰直線を求める方法です。

---

## Rで残差を確認する方法

線形回帰モデルを作成すると、

```r
model <- lm(y ~ x, data = df)
```

残差は

```r
residuals(model)
```

で取得できます。

残差プロットは

```r
plot(model)
```

または

```r
plot(fitted(model), residuals(model))
abline(h = 0)
```

で確認できます。

---

## よくある質問

### 残差が0ならどういう意味？

モデルの予測値と観測値が完全に一致しています。

---

### 残差が大きいと悪いモデル？

必ずしもそうではありません。

外れ値や重要な説明変数の不足など、さまざまな原因が考えられるため、残差のパターンを確認することが重要です。

---

### 残差はマイナスでもよい？

もちろん問題ありません。

マイナスは「予測値の方が大きかった」ことを意味するだけです。

---

## まとめ

残差とは、観測値と予測値との差であり、統計モデルの良し悪しを評価するための最も基本的な指標です。

回帰分析では、係数やP値だけを見るのではなく、残差の分布や残差プロットを確認することで、モデルの仮定が満たされているかを判断できます。

統計解析の質を高めるためには、「残差を見る習慣」を身につけることが非常に重要です。
