# EndNoteでジャーナルの引用スタイル（Output Style）を追加・インストールする方法

論文を投稿する際、多くの学術雑誌では独自の参考文献スタイル（Output Style）が用意されています。

EndNoteでは、このOutput Styleを追加することで、投稿規定に合わせた参考文献を自動で作成できます。

この記事では、一般的なジャーナルのOutput Styleを追加する方法を解説します。

---

# Output Styleとは？

Output Styleとは、

- 本文中の引用形式
- 参考文献リスト
- 著者名の表示方法
- 雑誌名の略称
- DOIやページ番号の表示

などを自動で整えてくれる設定ファイルです。

多くの出版社（Springer、Elsevier、Wileyなど）は、EndNote用のOutput Styleを公開しています。

---

# Step 1. 投稿規定を確認する

まず投稿予定の雑誌の

**Instructions for Authors**

または

**Submission Guidelines**

を確認します。

多くの雑誌では

```
EndNote Style
```

あるいは

```
Reference Style
```

というリンクがあります。

ZIPファイルまたはENSファイルをダウンロードします。

---

# Step 2. ZIPファイルを解凍する

ダウンロードしたZIPを解凍すると、

```
○○.ens
```

というファイルがあります。

これがOutput Styleです。

---

# Step 3. EndNoteで開く

.ensファイルをダブルクリックすると、

EndNoteが起動します。

---

# Step 4. Save Asで保存する

EndNoteで

```
File
↓

Save As
```

を選択します。

例えば

```
JJO

Nature

IOVS
```

など分かりやすい名前で保存します。

保存すると自動的にEndNoteへ登録されます。

---

# Step 5. Output Styleとして選択する

EndNote上部の

```
Style
```

から選択できます。

見つからない場合は

```
Select Another Style...
```

をクリックして検索します。

---

# Wordで利用する

Wordでは

**EndNoteタブ**

↓

**Style**

↓

使用したいジャーナル

を選択します。

その後は通常どおりInsert Citationを押すだけです。

---

# 引用形式が変わらない場合

引用形式が変わらない場合は、

```
Update Citations and Bibliography
```

をクリックしてください。

---

# JJOを例にすると

例えばJapanese Journal of Ophthalmology（JJO）では、

Submission Guidelinesに

```
EndNote Style (Download zip)
```

が用意されています。

ZIPをダウンロードし、この記事の手順で追加するだけで、JJOの投稿規定に合わせた参考文献を自動作成できます。

同様の方法は、

- Springer
- Elsevier
- Wiley
- Nature Portfolio
- Taylor & Francis

など、多くの出版社で共通です。

---

# まとめ

Output Styleを追加する流れは次の5ステップです。

1. 投稿規定からEndNote Styleをダウンロードする
2. ZIPファイルを解凍する
3. .ensファイルをEndNoteで開く
4. Save Asで保存する
5. WordまたはEndNoteでStyleを選択する

一度追加してしまえば、投稿先を変更した場合でもStyleを切り替えるだけで参考文献を自動変換できます。
