# なぜ私はWordPressではなくGitHub Pagesを選んだのか

ホームページを作ろうと考えたとき、多くの人はWordPressを思い浮かべるかもしれません。実際、私も最初はWordPressから始めることを考えていました。

しかし、いろいろ調べて検討した結果、私はまずGitHub Pagesを選ぶことにしました。

これは、「GitHub Pagesの方が優れている」という意味ではありません。私の現在の目的やライフスタイルには、GitHub Pagesの方が合っていると判断したからです。

## 私がホームページに求めているもの

私がホームページを作る目的は、大きく5つあります。

* 研究成果をまとめる
* 論文やGitHubのコードを紹介する
* ブログを書く
* 将来の共同研究につながる窓口を作る
* 研究活動の記録を残す

つまり、ホームページ自体で収益を上げることよりも、研究活動の基盤を作ることが第一の目的です。

## GitHubとの親和性

現在、私は解析に使用したRコードをGitHubで公開しています。

GitHub PagesはGitHubと一体化しているため、コードとホームページを自然につなげることができます。

論文を公開したら、その解析コードへのリンクを掲載し、READMEからホームページへ誘導することもできます。

研究成果、コード、ブログが一つの場所に集まる点は、大きな魅力でした。

## 維持管理の負担が少ない

現在は、小さな子どもの子育てをしながら、臨床と研究を両立しています。

そのため、ホームページの管理に多くの時間を使うことはできません。

GitHub Pagesはサーバー管理やWordPress本体・プラグインの更新作業が不要で、記事を書くことに集中できます。

限られた時間を考えると、このシンプルさは非常に大きなメリットでした。

## Markdownで記事を書ける

普段から論文ではMarkdownやGitHubを使う機会が増えています。

Markdownは装飾に時間を取られず、内容に集中できます。

私はデザインよりも、「良い記事を積み重ねること」の方が重要だと考えています。

## 費用がほとんどかからない

GitHub Pagesは無料で利用できます。

もちろん、独自ドメインを取得すれば多少の費用はかかりますが、WordPressと比較すると維持費は非常に低く抑えられます。

まずは継続できる環境を作ることを優先しました。

## WordPressを否定しているわけではない

もちろん、WordPressには多くの魅力があります。

* デザインの自由度が高い
* SEO対策が充実している
* 広告やアフィリエイトとの相性が良い
* プラグインが豊富

もし将来的にブログが大きく成長し、本格的に収益化を目指すのであれば、WordPressへ移行する可能性も十分にあります。

実際、私もその選択肢は考えています。

## 今は「書くこと」が最優先

ホームページは作ることが目的ではありません。

大切なのは、価値のある情報を継続して発信することです。

まずはGitHub Pagesで研究、プログラミング、眼科診療について記事を書き続けたいと思っています。

その結果として記事が積み重なり、より高機能な環境が必要になったときに、WordPressへの移行を検討すれば十分だと考えています。

現時点では、私にとってGitHub Pagesは「最も始めやすく、最も続けやすい選択」でした。
