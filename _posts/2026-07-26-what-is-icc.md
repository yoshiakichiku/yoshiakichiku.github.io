ICC（Intraclass Correlation Coefficient：級内相関係数）は、**測定の信頼性や再現性を評価するための代表的な統計指標**です。

医学論文では、

* 「ICC = 0.95」
* 「Excellent agreement」
* 「ICC(2,1)」

といった表現をよく見かけます。

しかし、初めてICCを学ぶと、

* ICCとは何を表しているのか？
* 相関係数とは何が違うのか？
* どのICCを使えばよいのか？

と疑問に思う人も多いでしょう。

この記事では、ICCの基本的な考え方を、研究初心者向けに分かりやすく解説します。

---

## ICCとは？

ICCは、

> **同じ対象を繰り返し測定したとき、どれだけ一貫した結果が得られるか**

を表す指標です。

例えば、OCTで網膜厚を3回測定したとします。

患者A

```
281
280
282
```

患者B

```
356
355
357
```

どちらの患者も測定値はほとんど変わりません。

このような測定では、ICCは高くなります。

一方、

患者A

```
281
310
267
```

患者B

```
356
330
372
```

のように測定値が大きくばらつけば、ICCは低くなります。

つまり、

**ICCが高いほど、「繰り返し測定しても同じような結果が得られる」ことを意味します。**

---

## ICCと相関係数は何が違う？

ICCは相関係数と混同されることがあります。

しかし、両者は目的が異なります。

例えば、

身長を2回測定したとします。

2回目の測定値がすべて

```
1回目 + 10 cm
```

だった場合、

相関係数はほぼ1になります。

しかし、

明らかに測定値は一致していません。

ICCは、このような「一致しているかどうか」を評価します。

つまり、

* **相関係数：順位が似ているか**
* **ICC：測定値そのものが一致しているか**

という違いがあります。

---

## ICCは何を利用して計算しているのか？

ICCは、

データ全体のばらつきを

* 個人差
* 測定誤差

に分けて考えます。

もし、

患者ごとの差が大きく、

測定誤差が小さければ、

ICCは1に近づきます。

逆に、

測定誤差が大きければ、

ICCは0に近づきます。

つまり、

> **測定誤差が全体のばらつきに占める割合が小さいほど、ICCは高くなる**

ということです。

---

## ICCの値はどう解釈する？

よく使われる目安は次の通りです。

|       ICC | 解釈        |
| --------: | --------- |
|     <0.50 | Poor      |
| 0.50–0.75 | Moderate  |
| 0.75–0.90 | Good      |
|     >0.90 | Excellent |

例えば、

```
ICC = 0.98
```

なら、

非常に高い再現性があると考えられます。

---

## ICCにも種類がある

実は、

ICCには多くの種類があります。

代表的なのは

* ICC(1,1)
* ICC(2,1)
* ICC(3,1)

です。

これらは、

* 測定者をランダム効果と考えるか
* 固定効果と考えるか
* 単回測定か平均値か

によって使い分けます。

医学論文では、

どのICCを使用したかを必ず記載する必要があります。

---

## 私の研究ではどう使ったか

私が行ったOCTの再現性研究では、

各眼を3回測定しました。

解析には線形混合効果モデルを用い、

* 患者間分散
* 左右眼間分散
* 測定誤差

を推定しました。

ICCは、

これらの分散成分を利用して計算しています。

この方法では、

単純なICCだけでなく、

Repeatability Coefficient（RC）や

Within-subject Standard Deviation（Sw）

も同時に評価できます。

---

## ICCだけでは十分ではない

ICCは非常に便利な指標ですが、

ICCだけを見ればよいわけではありません。

例えば、

ICCが高くても、

測定誤差が数十μmあれば、

臨床的には問題になる可能性があります。

そのため、

最近の再現性研究では、

* ICC
* Bland–Altman解析
* Sw
* Repeatability Coefficient

などを組み合わせて評価することが一般的です。

---

## まとめ

ICCは、

**「測定値がどれだけ一貫しているか」を評価するための代表的な統計指標**です。

ポイントをまとめると、

* ICCは再現性・信頼性を評価する指標
* 相関係数とは目的が異なる
* 測定誤差が小さいほどICCは高くなる
* ICCには複数の種類がある
* ICCだけではなく、SwやRCもあわせて評価するとより実践的

再現性研究を行う研究者にとって、ICCは最初に理解しておきたい統計指標の一つです。

今後の記事では、

* ICC(1)、ICC(2)、ICC(3)の違い
* RでICCを計算する方法
* 線形混合効果モデルからICCを計算する方法
* ICCとRepeatability Coefficientの関係

について、さらに詳しく解説していきます。
