ICC（Intraclass Correlation Coefficient：級内相関係数）は、測定値の信頼性や再現性を評価するために広く使われる統計指標です。

Rでは、ICCを計算できるパッケージが複数あります。その中でも代表的なのが、次の2つです。

* `psych`パッケージ
* `irr`パッケージ

どちらでもICCを計算できますが、関数の使い方や出力形式が異なります。

この記事では、同じサンプルデータを使って両者を比較しながら、RでICCを計算する基本的な方法を解説します。

## ICCを計算する前に決めること

ICCには複数の種類があります。

解析を始める前に、少なくとも次の3点を決める必要があります。

1. 一元配置モデルか、二元配置モデルか
2. 絶対一致を評価するか、一貫性を評価するか
3. 1回の測定値か、複数回の平均値か

例えば、複数の検者をより大きな検者集団へ一般化し、1回の測定値について絶対一致を評価したい場合は、一般にICC(2,1)を選択します。

一方、特定の検者だけを対象として一貫性を評価する場合は、ICC(3,1)が候補になります。

ICCを計算する前に、研究デザインに合った種類を決めておくことが重要です。

## サンプルデータを作成する

今回は、10人の対象者を3人の検者が測定したと仮定します。

ICC用のデータは、一般に次のような横長形式にします。

* 1行：1人の対象者
* 1列：1人の検者または1回の測定

```r
ratings <- data.frame(
  rater1 = c(280, 295, 310, 325, 340, 355, 370, 385, 400, 415),
  rater2 = c(282, 294, 313, 323, 342, 358, 368, 388, 398, 417),
  rater3 = c(279, 297, 309, 327, 338, 354, 373, 383, 402, 413)
)

ratings
```

このデータでは、対象者ごとの測定値には大きな差がありますが、同じ対象者に対する3人の検者の測定値は比較的近くなっています。

したがって、高いICCが得られることが予想されます。

## パッケージをインストールする

初回のみ、次のコードでパッケージをインストールします。

```r
install.packages("psych")
install.packages("irr")
```

解析時には、パッケージを読み込みます。

```r
library(psych)
library(irr)
```

`psych`では関数名が大文字の`ICC()`、`irr`では小文字の`icc()`である点に注意してください。

## psychパッケージでICCを計算する

`psych`パッケージでは、次のように計算します。

```r
psych_result <- psych::ICC(ratings)

psych_result
```

`psych::ICC()`は、Shrout and Fleissの分類に基づく複数のICCをまとめて出力します。具体的には、ICC1、ICC2、ICC3と、それぞれの平均測定版が表示されます。信頼区間も同時に計算されます。

主に表示されるICCは次の6種類です。

| psychの表示 | 一般的な意味                  |
| -------- | ----------------------- |
| ICC1     | 一元配置、1回測定               |
| ICC2     | 二元配置ランダム、絶対一致、1回測定      |
| ICC3     | 二元配置混合、または固定検者、一貫性、1回測定 |
| ICC1k    | 一元配置、平均測定               |
| ICC2k    | 二元配置ランダム、絶対一致、平均測定      |
| ICC3k    | 二元配置混合、または固定検者、一貫性、平均測定 |

例えば、ICC(2,1)を確認したい場合は、出力の`ICC2`の行を確認します。

ICC(3,1)を確認したい場合は、`ICC3`の行を確認します。

### 結果の表だけを確認する

`psych::ICC()`の結果から、ICCの一覧表だけを取り出すこともできます。

```r
psych_result$results
```

特定の行だけを取り出す場合は、次のように書けます。

```r
psych_result$results["ICC2", ]
```

ただし、パッケージのバージョンによって出力オブジェクトの列名や構造が変わる可能性があります。解析前に次のコードで構造を確認しておくと安全です。

```r
str(psych_result)
```

## irrパッケージでICCを計算する

`irr`パッケージでは、計算したいICCを引数で明示します。

基本形は次の通りです。

```r
irr::icc(
  ratings,
  model = "twoway",
  type = "agreement",
  unit = "single"
)
```

`irr::icc()`では、主に次の引数を指定します。

| 引数      | 選択肢                             | 意味         |
| ------- | ------------------------------- | ---------- |
| `model` | `"oneway"` / `"twoway"`         | 一元配置か二元配置か |
| `type`  | `"agreement"` / `"consistency"` | 絶対一致か一貫性か  |
| `unit`  | `"single"` / `"average"`        | 1回測定か平均測定か |

`irr`の公式ドキュメントでは、データは行が対象者、列が検者となる行列またはデータフレームとして入力します。また、ICCの推定値に加え、F検定と信頼区間も計算されます。

## ICC(2,1)を計算する

二元配置ランダム効果モデル、絶対一致、1回測定のICCを計算する場合は、次のように指定します。

```r
icc_2_1 <- irr::icc(
  ratings,
  model = "twoway",
  type = "agreement",
  unit = "single"
)

icc_2_1
```

これは一般に、ICC(2,1)またはICC(A,1)に対応します。

想定される研究場面は、次のようなものです。

* 同じ対象者を複数の検者が測定した
* 検者をより大きな検者集団へ一般化したい
* 測定値そのものの一致を評価したい
* 実際には1回の測定値を使用する

## ICC(2,k)を計算する

複数検者の平均値について絶対一致を評価する場合は、`unit = "average"`とします。

```r
icc_2_k <- irr::icc(
  ratings,
  model = "twoway",
  type = "agreement",
  unit = "average"
)

icc_2_k
```

この場合は、3人の検者による測定値の平均を使用したときの信頼性を評価します。

一般に、単回測定よりも複数回の平均値の方が測定誤差の影響が小さくなるため、ICC(2,k)はICC(2,1)より高くなりやすい傾向があります。

ただし、論文で平均測定ICCを報告する場合は、実際の臨床や研究でも同じ回数の平均値を使用することが前提です。

## ICC(3,1)に相当する解析

特定の検者を対象とし、検者間の系統的な平均差を許容して一貫性を評価する場合は、次のように指定します。

```r
icc_3_1 <- irr::icc(
  ratings,
  model = "twoway",
  type = "consistency",
  unit = "single"
)

icc_3_1
```

これは一般にICC(3,1)またはICC(C,1)に相当します。

例えば、研究に参加した特定の3人の検者だけについて信頼性を評価し、他の検者へ一般化することを目的としない場合に候補となります。

## 結果の値だけを取り出す

`irr::icc()`の結果からICCの推定値だけを取り出すには、`$value`を使います。

```r
icc_2_1$value
```

95%信頼区間の下限と上限は、次のように取得できます。

```r
icc_2_1$lbound
icc_2_1$ubound
```

結果をデータフレームに整理する場合は、次のように書けます。

```r
icc_summary <- data.frame(
  ICC = icc_2_1$value,
  lower_95_CI = icc_2_1$lbound,
  upper_95_CI = icc_2_1$ubound
)

icc_summary
```

論文用の表やCSVへ出力するときに便利です。

## psychとirrの結果を比較する

同じICCモデルを指定すれば、`psych`と`irr`では基本的に同じ考え方に基づく結果が得られます。

ICC(2,1)を比較する例は次の通りです。

```r
psych_result <- psych::ICC(ratings)

irr_result <- irr::icc(
  ratings,
  model = "twoway",
  type = "agreement",
  unit = "single"
)

psych_result$results["ICC2", ]
irr_result
```

ただし、パッケージによって次の点が異なることがあります。

* 表示される名称
* 結果の丸め方
* 信頼区間の表示形式
* 欠測値の処理
* 内部で使用する推定方法
* 出力オブジェクトの構造

そのため、数値がわずかに異なる場合は、パッケージ名だけでなく、モデル、絶対一致か一貫性か、単回測定か平均測定かを確認する必要があります。

## psychとirrの違い

両者の特徴を整理すると、次のようになります。

| 項目      | psych                | irr              |
| ------- | -------------------- | ---------------- |
| 関数      | `ICC()`              | `icc()`          |
| ICCの選び方 | 複数種類をまとめて出力          | 引数で1種類を明示        |
| 初心者の確認  | 種類を一覧で比較しやすい         | 条件とICCの対応を理解しやすい |
| 出力      | 6種類のICCを一覧表示         | 指定したICCを詳しく表示    |
| 信頼区間    | あり                   | あり               |
| 欠測値     | `lmer = TRUE`で欠測を扱える | リストワイズで除外        |
| 向いている用途 | ICCの候補を比較したいとき       | 事前に決めたICCを実行するとき |

`psych::ICC()`は、6種類のICCをまとめて確認できるため、モデル間の違いを比較したいときに便利です。また、現在のドキュメントでは、既定で`lme4::lmer()`を利用し、欠測値を扱えるとされています。

一方、`irr::icc()`は、`model`、`type`、`unit`を明示して1つのICCを計算します。解析条件がコード上で分かりやすいため、研究計画でICCの種類が決まっている場合に使いやすい方法です。欠測値はリストワイズで除外されます。

## どちらを使えばよい？

私なら、目的に応じて次のように使い分けます。

### ICCの種類を学びたい場合

`psych::ICC()`が分かりやすいです。

```r
psych::ICC(ratings)
```

1回の実行で複数のICCが表示されるため、ICC1、ICC2、ICC3の違いを確認できます。

### 使用するICCが決まっている場合

`irr::icc()`が分かりやすいです。

```r
irr::icc(
  ratings,
  model = "twoway",
  type = "agreement",
  unit = "single"
)
```

解析条件がコードに明記されるため、後から見返したときにも、どのICCを計算したのかが分かりやすくなります。

### 再現可能な研究コードとして残す場合

どちらを使っても構いませんが、次の情報をコード内のコメントとして残すことが重要です。

```r
# ICC(2,1)
# Two-way random-effects model
# Absolute agreement
# Single measurement
icc_result <- irr::icc(
  ratings,
  model = "twoway",
  type = "agreement",
  unit = "single"
)
```

パッケージ名だけでは、どのICCを選択したかは十分に伝わりません。

## 欠測値がある場合の注意

`irr::icc()`では、欠測値を含む対象者の行がリストワイズで除外されます。つまり、3人の検者のうち1人でも値が欠けている場合、その対象者全体が解析から除外されます。

```r
ratings_missing <- ratings
ratings_missing[3, 2] <- NA

irr::icc(
  ratings_missing,
  model = "twoway",
  type = "agreement",
  unit = "single"
)
```

欠測が多い場合、解析対象者数が大きく減る可能性があります。

`psych::ICC()`は、既定では`lmer = TRUE`となっており、線形混合効果モデルを利用して欠測を含むデータを扱えます。

```r
psych::ICC(
  ratings_missing,
  lmer = TRUE
)
```

ただし、欠測がある研究では、単に計算できたかどうかだけではなく、欠測の発生理由や解析対象数も報告する必要があります。

## 論文には何を書けばよい？

ICCを論文で報告するときは、単に次のように書くだけでは不十分です。

> ICC was 0.95.

少なくとも、次の内容を記載します。

* ICCの種類
* 一元配置か二元配置か
* ランダム効果か混合効果か
* 絶対一致か一貫性か
* 単回測定か平均測定か
* 95%信頼区間
* 使用したソフトウェアとパッケージ

例えば、ICC(2,1)を使用した場合は、次のように記載できます。

> Inter-rater reliability was evaluated using a two-way random-effects, absolute-agreement, single-measure intraclass correlation coefficient [ICC(2,1)].

Rについては、次のように追記できます。

> The ICC and its 95% confidence interval were calculated using the `icc()` function in the `irr` package in R.

## ICCを計算するときの注意点

### 数値だけを見てICCを選ばない

複数のICCを計算し、最も高い値を採用する方法は適切ではありません。

ICCの種類は、結果を見る前に研究デザインと利用目的から決める必要があります。

### 単回測定と平均測定を混同しない

3回測定の平均値を実際に使用するなら平均測定ICCを選択できます。

しかし、実際の臨床では1回だけ測定するにもかかわらず、平均測定ICCだけを報告すると、信頼性を過大に見せる可能性があります。

### 絶対一致と一貫性を区別する

検者間に一定の測定差があっても、順位が保たれていれば一貫性ICCは高くなることがあります。

測定値そのものが一致する必要がある研究では、絶対一致を選択します。

### ICCだけで測定誤差の大きさは分からない

ICCは対象者間のばらつきにも影響されます。

そのため、ICCが高くても、測定誤差の絶対量が小さいとは限りません。

再現性研究では、必要に応じて次の指標も併記します。

* Within-subject standard deviation（Sw）
* Standard error of measurement（SEM）
* Repeatability coefficient（RC）
* Bland–Altman解析

## まとめ

Rでは、`psych`と`irr`のどちらを使ってもICCを計算できます。

両者の違いを簡単にまとめると、次のようになります。

* `psych::ICC()`は複数種類のICCを一覧で確認できる
* `irr::icc()`は計算するモデルを引数で明示できる
* `psych`はICCの種類を比較するときに便利
* `irr`は事前に決めたICCを再現可能なコードとして残しやすい
* 欠測値の処理方法には違いがある
* パッケージを選ぶ前に、研究デザインからICCの種類を決める

私自身は、ICCの種類を確認するときには`psych`を使い、最終的な解析コードでは条件を明示しやすい`irr`を使う方法が分かりやすいと考えています。

ただし、左右眼、反復測定、患者内に眼が入れ子になったデータなど、より複雑な階層構造では、従来型のICC関数だけでは不十分な場合があります。

そのような場合は、線形混合効果モデルから分散成分を推定し、研究デザインに合ったICCを計算する方法を検討します。
