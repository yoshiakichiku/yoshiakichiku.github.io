---

# Markdownとは？

Markdown（マークダウン）は、**文章を読みやすく構造化するための軽量マークアップ言語（Lightweight Markup Language）**です。

例えば、

```
# タイトル

## 見出し

- 箇条書き
```

と書くだけで、

# タイトル

## 見出し

- 箇条書き

のように表示されます。

HTMLのような複雑なタグを書く必要がなく、普通の文章を書く感覚で利用できます。

---

# なぜMarkdownが人気なのか？

Markdownが広く利用される理由は、とにかくシンプルだからです。

メリットはたくさんあります。

- 覚えることが少ない
- テキストだけなので軽い
- Wordのようにレイアウトが崩れない
- GitHubでそのまま表示できる
- ブログや論文にも利用できる
- AIとの相性が非常によい

現在では

- GitHub
- GitHub Pages
- Jekyll
- Hugo
- Obsidian
- Notion（一部）
- VS Code

など、多くのサービスがMarkdownに対応しています。

---

# MarkdownとWordの違い

| Markdown | Word |
|-----------|------|
| テキストだけ | 独自ファイル形式 |
| 軽い | やや重い |
| レイアウト崩れが少ない | 環境によって崩れることがある |
| Gitで管理できる | 管理しにくい |
| AIとの相性がよい | やや苦手 |
| ブログ向き | 印刷向き |

Wordは印刷物を作るのに優れています。

一方で、

- ブログ
- GitHub
- Webページ
- README

などではMarkdownの方が圧倒的に使いやすいでしょう。

# Markdownでできること

Markdownでは様々な表現ができます。

## 見出し

```
# 大見出し

## 中見出し

### 小見出し
```

---

## 箇条書き

```
- りんご
- バナナ
- みかん
```

表示

- りんご
- バナナ
- みかん

---

## 番号付きリスト

```
1. はじめに
2. 方法
3. 結果
```

表示

1. はじめに
2. 方法
3. 結果

---

## 強調

```
**太字**
```

表示

**太字**

---

## イタリック

```
*斜体*
```

表示

*斜体*

---

## リンク

```
[Google](https://www.google.com)
```

---

## 画像

```

```

---

## 引用

```

```

表示
