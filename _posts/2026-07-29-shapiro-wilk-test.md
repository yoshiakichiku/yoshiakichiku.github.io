Shapiro-Wilk検定は、データが正規分布に従うかどうかを調べる代表的な正規性検定です。

t検定や分散分析など、多くの統計手法では正規分布が仮定されるため、解析前に正規性を確認する際によく利用されます。

ただし、P値だけで正規性を判断するのではなく、QQプロットなどのグラフも併せて確認することが重要です。

---

# Shapiro-Wilk検定とは？

Shapiro-Wilk検定（Shapiro-Wilk test）は、**データが正規分布に従っているかどうか**を調べるための統計学的検定です。

1965年にSamuel ShapiroとMartin Wilkによって提案され、現在でも最も広く利用されている正規性検定の1つです。

---

# なぜ正規性を調べるのか？

多くの統計解析では、

- t検定
- 分散分析（ANOVA）
- 線形回帰
- 線形混合効果モデル

などで正規分布が仮定されています。

もしデータが大きく正規分布から外れている場合、

- P値
- 信頼区間
- 回帰係数

などの推定結果が適切でなくなる可能性があります。

そのため、解析前に正規性を確認することが重要です。

---

# 帰無仮説と対立仮説

Shapiro-Wilk検定では、

**帰無仮説（H₀）**

> データは正規分布に従う

**対立仮説（H₁）**

> データは正規分布に従わない

となります。

つまり、

- **P ≥ 0.05**
  → 正規分布であることを否定できない

- **P < 0.05**
  → 正規分布ではない可能性が高い

と解釈します。

---

# Shapiro-Wilk検定の統計量

Shapiro-Wilk検定では、

$$
W=
\frac
{\left(\sum_{i=1}^{n}a_ix_{(i)}\right)^2}
{\sum_{i=1}^{n}(x_i-\bar{x})^2}
$$

という統計量を計算します。

ここで、

- \(x_{(i)}\)：小さい順に並べたデータ
- \(a_i\)：正規分布から計算される係数
- \(\bar{x}\)：平均値

を表します。

Wが1に近いほど、データは正規分布に近いことを意味します。

---

# 例

例えば20人の身長を測定したところ、

```
P = 0.42
```

だったとします。

この場合、

帰無仮説は棄却されないため、

**正規分布から有意に外れているとは言えない**

と解釈します。

一方、

```
P = 0.003
```

なら、

正規分布ではない可能性が高いと判断します。

---

# P値だけでは判断できない理由

Shapiro-Wilk検定には注意点があります。

## 症例数が少ない場合

症例数が少ないと、

正規分布から多少外れていても

有意差が出ません。

つまり、

**異常を見逃す可能性があります。**

---

## 症例数が多い場合

逆に症例数が非常に多いと、

ごくわずかな歪みでも

```
P < 0.001
```

になることがあります。

実際には解析上ほとんど問題がなくても、

「有意差あり」

となってしまいます。

---

# QQプロットも確認しよう

そのため、

Shapiro-Wilk検定だけではなく、

QQプロット（Quantile-Quantile Plot）

も併せて確認することが推奨されています。

理想的には、

```
●

  ●

    ●

      ●

        ●
```

のように、

点が一直線上に並びます。

大きく曲がる場合は、

正規分布から外れている可能性があります。

---

# t検定やANOVAでは必須？

必ずしもそうではありません。

実際には、

サンプルサイズが十分大きければ、

中心極限定理により

多少正規分布から外れていても、

t検定やANOVAは比較的頑健であることが知られています。

そのため近年では、

Shapiro-Wilk検定だけで解析手法を変更することはあまり推奨されません。

---

# 残差の正規性を確認することが重要

回帰分析では、

**目的変数そのものではなく、残差が正規分布に従うこと**

が仮定されています。

そのため、

回帰分析では

- 残差のQQプロット
- 残差ヒストグラム
- Shapiro-Wilk検定

などを用いて、

残差の正規性を評価します。

---

# RでShapiro-Wilk検定を行う方法

Rでは

```r
shapiro.test(x)
```

だけで実行できます。

例えば

```r
x <- c(12, 14, 15, 16, 18, 20)

shapiro.test(x)
```

結果は

```text
Shapiro-Wilk normality test

W = 0.97
p-value = 0.81
```

のように表示されます。

---

# よくある質問

## P値が0.05より大きければ正規分布？

「正規分布である」と証明されたわけではありません。

**正規分布ではないという十分な証拠が得られなかった**

という意味です。

---

## P値が0.05未満なら解析できない？

いいえ。

データ数や解析目的によっては、

そのまま解析を行うこともあります。

必要に応じて

- ノンパラメトリック検定
- データ変換
- ロバスト統計

などを検討します。

---

## Kolmogorov-Smirnov検定との違いは？

どちらも正規性検定ですが、

一般にはShapiro-Wilk検定の方が検出力が高いとされ、

現在ではShapiro-Wilk検定が推奨されることが多くなっています。

---

# まとめ

Shapiro-Wilk検定は、データが正規分布に従うかどうかを調べる代表的な正規性検定です。

ただし、P値だけで正規性を判断するのではなく、QQプロットやヒストグラムなどの視覚的評価も併用することが重要です。

特に回帰分析では、目的変数ではなく「残差」の正規性を確認することが、適切な統計解析につながります。
