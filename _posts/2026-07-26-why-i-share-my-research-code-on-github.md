# Why I Share My Research Code on GitHub

In recent years, reproducibility has become an increasingly important topic in scientific research. While published articles describe study designs, statistical methods, and results, they often cannot include every detail required to reproduce the analyses exactly.

For this reason, I have decided to make the statistical code used in my research publicly available on GitHub whenever possible.

## Improving Reproducibility

One of the main goals of sharing code is to improve reproducibility.

Even when a statistical method is described in detail, there are often many implementation choices that are difficult to explain completely within the limited space of a journal article. By providing the original analysis scripts, readers can better understand how the analyses were performed and reproduce the results more accurately.

## Supporting Other Researchers

Many ophthalmology researchers perform similar statistical analyses but may spend considerable time implementing the same methods from scratch.

If my code can save someone a few hours—or even a few days—of work, then sharing it has already been worthwhile. I hope these repositories serve as practical examples that researchers can adapt to their own projects.

## Transparency

Sharing code also encourages transparency.

Making analysis scripts publicly available allows others to examine the analytical workflow, identify potential issues, and suggest improvements. Science advances through open discussion, and transparent code contributes to that process.

## Balancing Openness and Privacy

Although I aim to share as much as possible, patient privacy and institutional regulations always take priority.

For this reason, the original clinical datasets used in my studies are generally not publicly available. Instead, I provide anonymized sample datasets whenever appropriate so that users can understand the workflow without accessing confidential patient information.

## Why GitHub?

GitHub has become the standard platform for collaborative software development and open scientific computing.

It provides version control, issue tracking, and a permanent record of code development. More importantly, it allows researchers around the world to access, review, and improve analytical methods in an open environment.

## Looking Ahead

This is only the beginning.

I plan to continue sharing R scripts, analysis workflows, and software developed during my research projects. Over time, I hope these repositories will become useful resources for researchers working in ophthalmology, medical imaging, and clinical data analysis.

If these resources help make research more reproducible, more transparent, or simply a little easier for someone else, then this project will have achieved its purpose.
